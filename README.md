# Deadraon.github.io

Personal portfolio and project repository built with modern web technologies.

## 🛠️ Tech Stack

This project is primarily built with:

- **TypeScript** (97.4%) - Type-safe JavaScript for robust development
- **CSS** (2.3%) - Styling and layout
- **JavaScript** (0.3%) - Interactive features and utilities

## 📋 About

This is a GitHub Pages repository hosting a personal portfolio website. The project leverages TypeScript for maintainability and CSS for responsive design.

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed on your machine
- Git for version control

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Deadraon/Deadraon.github.io.git
cd Deadraon.github.io
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

## 📝 Development

### Project Structure

```
├── src/              # Source files (TypeScript/CSS)
├── dist/             # Compiled output
├── package.json      # Project dependencies and scripts
└── README.md         # This file
```

### Building

To build the project for production:

```bash
npm run build
```
